## What I'm building

**[Lenny's Board Room](https://lennys-board-room.replit.app/)** is a RAG-powered advisory board that queries Lenny Rachitsky's podcast archive against your PM problem. Five advisors debate it in their own voice, then Lenny adds the cross-pattern insight. 2,178 chunks from 50 guests, gpt-4o-mini for retrieval and gpt-4o for synthesis, pgvector on Supabase. Built for the Lenny x Replit buildathon.

**[SignalDesk](https://github.com/saurabhsudhir15/SignalDesk)** is a Telegram-native agentic AI that tracks investment signals from financial influencer content. Extracts ticker, stance, and reasoning from YouTube links, PDFs, and posts. Stack: n8n, GPT-4o-mini, Supabase with pgvector. Evaluated at 97% precision on real influencer content.

**[RAG Simulator](https://github.com/saurabhsudhir15/rag_simulator)** is an interactive 5-step walkthrough of how retrieval-augmented generation works, built to make the pipeline intuitive for PMs and non-engineers.

**[Apply Connect 2.0](https://github.com/saurabhsudhir15/apply-connect-prototype)** is a PM case study and interactive prototype for a browser extension that pre-fills ATS application forms using LinkedIn profile data. Includes problem framing, RICE prioritization, PRD, and a clickable prototype.

**[FinCrime Case Study](https://github.com/saurabhsudhir15/fincrime-case-study-dashboard)** is an anonymized PM case study on synthetic identity fraud for an Indian SME neobank. Covers problem scoping, hypothesis testing, four recommendations, and a live dashboard simulation.
